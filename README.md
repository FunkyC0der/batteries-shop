# СИСТЕМІКА — batteries-shop

A statically exported Next.js catalog site for batteries, meters, and related energy equipment/services. Product and service data live as JSON files under `data/`.

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run build   # validate catalog, build the catalog projection, and produce the static export in out/
npm test        # run the Vitest suite
```
